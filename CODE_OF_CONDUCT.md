# Code of Conduct

## Our Commitment

We are committed to providing a friendly, respectful, and welcoming environment for everyone participating in this project.

## Expected Behavior

- Be respectful and professional.
- Communicate politely.
- Accept constructive feedback.
- Focus on improving the project.
- Respect different opinions and approaches.

## Unacceptable Behavior

- Harassment or discrimination.
- Personal attacks or insults.
- Offensive or inappropriate language.
- Deliberately disruptive behavior.

## Reporting

If you observe unacceptable behavior, please report it to the repository maintainer through GitHub.
