# Security Policy

## Reporting a Security Issue

If you discover a security vulnerability or security-related issue, please report it privately to the repository maintainer through GitHub rather than publicly disclosing the issue.

Please include:

- A clear description of the issue.
- Steps to reproduce it.
- Relevant screenshots or error messages.
- Any suggested mitigation, if available.

## Responsible Disclosure

Please allow the maintainer reasonable time to review and address security issues before public disclosure.
